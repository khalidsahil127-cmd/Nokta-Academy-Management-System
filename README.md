# Academy Management System Backend

# Phase 1
Secure RBAC-Based Backend using Node.js, Express, MongoDB

## Features
- System Model
- JWT Authentication
- Refresh Token Rotation
- RBAC Authorization
- Audit Logging
- Failed Access Logging
- Soft Delete
- Security Headers (Helmet)
- Rate Limiting
